Every coding agent, conducted from one Mac app.

Conductor plans your work, hands each part to the CLI that suits it, and keeps the whole run in one window. Codex, Claude Code, OpenCode, Antigravity and Kiro stay yours: signed in, on your machine.

Download for Mac View the source

Apple Silicon. Free and open source. Under active development.

Plan once, run in parallel.

Describe the task. A planner splits it into waves of steps that don't depend on each other, and each step goes to its own agent at the same time.

If an agent runs out of quota, the next CLI in line takes over and the plan says so. Nothing changes your files without your approval unless you set it to.

Agents with a computer of their own.

Give an agent a name, instructions and the CLIs it may use. It works inside its own Docker sandbox, with a browser, a terminal and files, and asks before anything risky.

Prefer your own browser? Agents can drive a separate Chrome profile on your Mac that runs out of your way, signed in where you are.

Workspace
The agent's own files. They outlive the container.
Shared
A common folder and notebook every agent can read, with locks so two never write at once.
Browser profile
Cookies and logins, so a site you signed into stays signed in.
Secrets
Kept in the macOS Keychain. Agents type them into forms by name and never see the value.

Flows that wait for your reply.

Chain agents into a flow, by hand or by describing it. Run it now or on a schedule. A reply step emails you and pauses until you answer, then carries on with what you said.

Local-first, on purpose.

Tasks, history and settings live in SQLite on your Mac. Credentials live in the Keychain. Each CLI keeps its own sign-in, and Conductor runs no server of its own: the work goes straight from your machine to the providers you already use.

Get started.

You need macOS, Node.js 22 or newer, and at least one agent CLI signed in. Docker Desktop is needed for sandboxed agents.

  1. Get the code.

    git clone https://github.com/mgm152002/Conductor.git
cd Conductor

  2. Install and start it.

    npm ci
npm run dev

  3. Open Agents, choose Download sandbox, then create an agent and give it a task.
